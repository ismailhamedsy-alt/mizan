# الميزان للمحاسبة — نسخة Windows جاهزة للبناء

## ما هذه النسخة؟
هذه نسخة Windows مبنية على مشروع Android المرجعي الذي تم رفعه، مع الحفاظ على الوظائف المحاسبية الأساسية وإضافة ربط Android LAN والاستيراد من قاعدة Android.

## تشغيل البرنامج
بعد فك الضغط على Windows 10/11:

1. ادخل إلى `desktop\mizan`.
2. شغّل `build-windows.cmd`.
3. عند اكتمال البناء ستجد البرنامج في `dist\Mizan.exe`.
4. للتشغيل لاحقاً استخدم `run-mizan.cmd`.

## إذا لم يكن .NET SDK مثبتاً
السكريبت يحاول تثبيت Microsoft .NET SDK 8 عبر WinGet تلقائياً. إذا لم يتوفر WinGet، ثبّت SDK من Microsoft ثم أعد تشغيل السكربت.

## تسجيل الدخول لأول مرة
اسم المستخدم: `admin`
PIN: `1234`
ثم أنشئ مستخدماً جديداً وغيّر PIN.

## بيانات البرنامج
قاعدة البيانات والإعدادات تحفظ تحت:
`%LOCALAPPDATA%\MizanDesktop`

## التحويل من Android
من الإعدادات يمكن:
- استيراد ملف SQLite من Android.
- اختبار الاتصال عبر الشبكة المحلية.
- جلب بيانات Android إلى Windows.
- تنفيذ مزامنة ثنائية.

## الوظائف المغطاة
المبيعات، المشتريات، المرتجعات، عروض الأسعار، المنتجات، العملاء والموردون، الصندوق، السندات، المصروفات، المخزون، الجرد والتسوية، FIFO، القيود، دليل الحسابات، التقارير، أسعار الصرف، كشف الحساب، المستخدمون، النسخ الاحتياطي، الاستعادة، سجل التدقيق، استيراد Android ومزامنة Android.

## إذا فشل البناء
شغّل `diagnose-build.cmd`. لا تحذف ملفات المصدر. أرسل محتوى `publish\build.log` أو آخر 30 سطراً منه.
