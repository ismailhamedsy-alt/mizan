# الميزان للمحاسبة — نسخة Windows / .NET 10

## البناء والتشغيل
1. فك المستودع/الحزمة على Windows 10 أو Windows 11 x64.
2. ثبّت .NET SDK 10.0.112 أو أحدث إصدار patch من سلسلة .NET 10.
3. شغّل `1-BUILD-MIZAN.cmd` من جذر المشروع.
4. بعد نجاح البناء افتح `desktop\mizan\dist\Mizan.exe`.
5. للتشغيل لاحقًا استخدم `2-RUN-MIZAN.cmd`.

## تسجيل الدخول
الافتراضي: اسم المستخدم `admin` ورمز الدخول `1234`.
إذا رفضت قاعدة البيانات القديمة الرمز، اضغط `استعادة دخول المدير` في شاشة الدخول. ستُعاد بيانات حساب المدير فقط ولن تحذف قاعدة البيانات أو الفواتير أو المنتجات.

## البيانات
تُحفظ قاعدة البيانات والإعدادات في:
`%LOCALAPPDATA%\MizanDesktop`

## المزامنة
من الإعدادات يمكن استيراد قاعدة Android، اختبار الاتصال بالشبكة المحلية، جلب بيانات Android إلى Windows، أو تنفيذ مزامنة ثنائية.

## التحقق
تنفّذ GitHub Actions على Windows:
- فحص جميع ملفات XAML ومعالجات الأحداث.
- Build وPublish باستخدام .NET 10.
- التحقق من EXE.
- اختبار الدخول على قاعدة جديدة، ترحيل الحساب القديم، استعادة الدخول، وإنشاء الواجهات الأساسية وتخطيطها، ثم التشغيل الطبيعي.
